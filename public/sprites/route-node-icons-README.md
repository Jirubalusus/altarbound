# Route node combat icons

- `crossed-swords-twemoji.png`: PNG downloaded from Twemoji CDN (`2694.png`) as an online PNG source, not generated from SVG in this project.
- `crown-twemoji.png`: PNG downloaded from Twemoji CDN (`1f451.png`) as an online PNG source, not generated from SVG in this project.
- `battle-crossed-swords.png`: local transparent PNG composed from the online crossed-swords PNG for Battle route nodes.
- `elite-crossed-swords-crown.png`: local transparent PNG composed from the online crossed-swords and crown PNGs for Elite Battle route nodes.

These are route-map semantic icons only. Unit/hero portraits remain reserved for team, recruit, reward, and battle screens. Boss route nodes intentionally use the faction final hero portrait resolved by code.
