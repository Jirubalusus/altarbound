# WoW/Warcraft character face icons

Cache-busted face/portrait-first character assets for unit, hero, battle and route UI.

This directory intentionally differs from `wow-assets/characters/` so browsers/mobile caches cannot keep older weapon/ability icon files such as the old Grunt axe icon.

Source pattern: `https://wow.zamimg.com/images/wow/icons/large/<wowIcon>.jpg`

See `catalog.json` for per-asset source URL. Review Blizzard/ZAM rights/licensing before production/commercial use.
