# WoW/Warcraft character icons

Character/unit/hero icons sourced from the Wowhead/ZAM WoW icon CDN (`wow.zamimg.com/images/wow/icons/large/...jpg`) for this prototype, then normalized to PNG. These replace generated/local placeholder sprites for the visible unit and hero cards/portraits. Review Blizzard/Wowhead/ZAM rights before public/commercial use.
