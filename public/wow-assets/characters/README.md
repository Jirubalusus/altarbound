# WoW/Warcraft character icons

These PNGs are 64x64 route/card character assets derived from public WoW/ZAM icon URLs.

Current pass: face/portrait-first icons. Weapon, spell, class-symbol and generic ability icons were replaced where possible with faces/heads/creature portraits so map/unit cards read as characters (e.g. Grunt uses `inv_misc_head_orc_01`, not an axe).

Source pattern: `https://wow.zamimg.com/images/wow/icons/large/<wowIcon>.jpg`

See `catalog.json` for per-asset source URL and icon id. Review Blizzard/ZAM rights/licensing before production/commercial use.
